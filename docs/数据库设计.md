# 数据库设计

## 范围与口径

依据 `backend/sql/homestay_db.sql`、增量脚本及当前 Entity、Mapper 和 Service 整理；以初始化脚本为字段和约束基准，实际部署库的迁移状态未确认。共 21 张建表脚本定义的表，其中 20 张可见应用读写，`sys_permission_audit` 未发现应用引用，使用情况未确认。

“必填”表示数据库列是否声明 `NOT NULL` 或主键，并不等同于 API 必填；有默认值的非空列可由数据库生成。未列出的逻辑关联不代表已创建外键。
