## 发现和处理

1. 日期格式错误、缺少参数、错误 JSON 原先落入通用异常处理并返回 HTTP 500。新增第三方控制器局部处理，返回 HTTP 400 和业务码 400；对应测试通过，不改变其他控制器的异常处理。
2. 修改主播时清空备注，MyBatis 非空更新策略会保留旧备注。改为显式设置备注字段，包括 null；隔离 MySQL 回归测试通过。

## Risk analysis

- 此阶段第三方房态不读取小程序订单；不能防止跨渠道重复预订，是已确认的范围边界。
- 现有订单与支付单元测试已运行；只验证了第三方写入前后小程序订单表行数不变，不能证明完整小程序 UI、支付及业务状态均无回归。
- 没有进行浏览器页面操作、不同屏幕宽度、日期组件及真实用户交互验收。
- 报表当前逐订单查询关联名称并按晚计算，大量历史订单时可能有性能压力，未做容量或压力测试。
- 现有数据库实际升级尚未执行；上线前需备份并在与目标环境一致的测试库核对增量迁移。
